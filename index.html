Ad blocking

Blocks ~70 ad and tracker networks

WebKit content-blocker rules plus cosmetic hiding. A YouTube script removes player ads. One shield button turns it off for a site.

Private tabs

Leave no trace

Cookies and storage are thrown away when you close the tab. Passwords aren't saved, and private tabs are left out of session restore.

Tab groups

A sidebar you can organize

Colored, collapsible, renameable groups with drag and drop. The vertical sidebar keeps long titles readable.

Passwords

Safespace integration

Fill saved logins from your Safespace vault and save new ones on submit. Logins wait while the vault is locked.

Start page

ORBIS-style start page

A big clock and session stats on a quiet canvas. Light, dark or system appearance.

Everyday

Session restore & default browser

Pick up where you left off, reopen closed tabs, and set LBrowser as your default browser.

  1. Download LBrowser-1.0.dmg from the latest release.
  2. Open it and drag LBrowser.app into Applications.
  3. Launch it. If macOS blocks it, go to System Settings → Privacy & Security → Open Anyway.
The app is ad-hoc signed and not notarized by Apple, which is why macOS asks the first time. A SHA-256 checksum is published next to the DMG.
# Needs full Xcode (SwiftUI macros aren't in the Command Line Tools)
git clone https://github.com/Replace-Big-Tech-Apps/LBrowser.git
cd LBrowser
./build.sh                      # → build/LBrowser.app
./build.sh --install            # also copies to /Applications
./build.sh --universal --dmg    # universal DMG
